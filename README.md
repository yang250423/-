# 黄峥读本（静态站）

- `index.html` — 封面、前言与目录，作为前言和目录的稿源
- `ch/*.html` — 第1–23章；第21章为编后评议，第22–23章为多多买菜专题
- `book.html`、`本分-黄峥这个人.epub` — 稿源生成的前言、第1–23章和微博附录
- `appendix/weibo.html` — 微博附录
- `yuanwen/` — 本人原文（所收公开文本）
- `originals/` — 本人作品、官方文件、媒体摘要及核验记录，逐页说明范围
- `dossier.html` — 时间线、事实、来源、缺口及更新日志
- `style.css` — 共享样式

相对链接，可部署到GitHub Pages子路径。网页直接可读；修改稿源后用Python 3.9+同步全书和电子书：

```sh
python3 build.py
python3 build.py --check
```

生成器只依赖标准库，自动发现从01连续编号的两位数字章节；首页目录仍须按序同步。产物保留证据标记、来源编号及链接。`--check`只读检查产物同步、站内链接和锚点、EPUB结构。`checks/github-actions.yml.example`是检查工作流示例，保留在示例位置；本轮检查在本机执行。

更新约定沿用前言：

- 引语、数字、日期有出处；区分发表日、事件日与核查日，记录版本和定位。
- 本人自述、公司/官方披露、记者及他人说法、作者分析分别说明；已核实只落实到具体主张。
- 合同文本、采购条件、实际履行、程序状态与裁判结果分开；检索未取得不等于不存在。
- 媒体仅摘要、短引及原链；同一文本转存、转载不重复计为独立证据。
- 稳定来源编号，同步章节、资料库、材料目录、全书与EPUB；保留其他作者已新增的材料。
- 捐赠承诺、到账与科研资助致谢分别取证；股权或创始人身份不替代具体经营参与证据。
