# 黄峥读本（静态站）

- `index.html` — 封面 + 前言 + 目录，作为前言与目录的稿源
- `book.html` — 全书通读，由稿源生成（前言 + 第 1–22 章 + 微博附录）
- `本分-黄峥这个人.epub` — EPUB 电子书（前言 + 第 1–22 章 + 微博附录）
- `ch/*.html` — 各章；第 21 章为 Codex 于 2026-10-19 增补的独立编后评议，第 22 章为多多买菜专题
- `appendix/weibo.html` — 附录 D：尚未找到可核实的黄峥本人微博账号
- `yuanwen/` — 本人原文（公开全文）
- `originals/` — 站内材料与出处：本人作品、官方文本或摘要、媒体摘要、核验记录；每页注明范围
- `dossier.html` — 公开资料库摘要
- `style.css` — 共享样式

相对链接，可部署到 GitHub Pages 子路径。网站可直接浏览；编辑稿源后，用 Python 3.9+ 同步全书和 EPUB：

```sh
python3 build.py
python3 build.py --check
```

`build.py` 只依赖标准库。编辑 `ch/*.html`、首页前言/目录和附录，再生成产物；全书与 EPUB 保留证据标记、来源编号和可点击出处。`--check` 只读检查产物同步、站内链接与锚点、EPUB 的 ZIP/XML/目录结构。checks/github-actions.yml.example 提供在推送和拉取请求时运行同一检查的工作流示例；启用时放入 .github/workflows/check.yml。本轮现有登录缺少 workflow 写入权限，因此保留示例，本机检查已经通过。

更新约定沿用前言：

- 引语、数字与日期必须有出处；记录材料发表日与本轮核验日，明确原文定位。
- 本人自述、公司/官方披露、媒体/他人说法、作者推断和待核实内容分别说明；“已核实”落实到具体主张。
- 承诺、实施与结果分开；诉方主张、被告答辩、程序状态与裁判结论分开；检索未找到不写成事情不存在。
- 媒体、访谈与付费论文保留摘要、短引和原链；不将重复转存或转载算作独立证据，不冒充已读未收录全文。
- 新材料使用稳定来源编号，说明能证明什么、不能证明什么，同步章文、资料库、材料目录与生成产物。
- 旧核验记录缺公开原件时保留来源状态；不因一次超时推导负面事实，不用科研资助致谢替代捐款到账证据。
